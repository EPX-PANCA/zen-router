Panduan Integrasi & URL Endpoints

Pilih aplikasi / klien di bawah untuk melihat cara konfigurasi, format token, dan endpoint yang digunakan.

1
Buat API Key
Klik tombol + Generate API Key di bagian atas dashboard untuk membuat token (contoh: zen-sk-xxxx...).
2
Export Environment Variables di Terminal
Arahkan Anthropic endpoint ke port 20128 Zen Router:
BASH / ZSH 
export ANTHROPIC_BASE_URL="http://localhost:20128"
export ANTHROPIC_API_KEY="YOUR_ZEN_KEY_HERE"  # (token zen-sk-...)
claude
1
Buka Settings Model di Editor Anda
Pilih provider OpenAI Compatible di Cursor, Cline, OpenCode, atau Roo Code.
2
Masukkan Parameter Konfigurasi
CURSOR / OPENCODE CONFIG 
Base URL:  http://localhost:20128/v1
API Key:   YOUR_ZEN_KEY_HERE  # (token zen-sk-...)
Model:     gemini-3.8-flash-high (atau gemini-2.5-flash / gpt-4o / claude-3-5-sonnet-20241022)
1
Gunakan Official OpenAI Python Library
Arahkan base_url ke Zen Router pada port 20128:
PYTHON (openai >= 1.0) 
from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:20128/v1",
    api_key="YOUR_ZEN_KEY_HERE"
)

response = client.chat.completions.create(
    model="gemini-3.8-flash-high",  # atau gemini-3.8-flash-medium, low, gemini-2.5-flash
    messages=[{"role": "user", "content": "Halo Zen Router!"}],
    stream=True
)

for chunk in response:
    if chunk.choices and chunk.choices[0].delta.content:
        print(chunk.choices[0].delta.content, end="", flush=True)
print()
1
OpenAI Chat Completion Endpoint (cURL)
CURL - OPENAI 
curl http://localhost:20128/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_ZEN_KEY_HERE" \
  -d '{
    "model": "gemini-3.8-flash-high",
    "messages": [{"role": "user", "content": "Hello!"}]
  }'
2
Anthropic Messages Endpoint (cURL)
CURL - ANTHROPIC 
curl http://localhost:20128/v1/messages \
  -H "Content-Type: application/json" \
  -H "x-api-key: YOUR_ZEN_KEY_HERE" \
  -H "anthropic-version: 2023-06-01" \
  -d '{
    "model": "claude-3-5-sonnet-20241022",
    "max_tokens": 1024,
    "messages": [{"role": "user", "content": "Hello Claude!"}]
  }'
